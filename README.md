# 碎页集 · SUIYEJI

> 把知识，撕成能记住的小块。

碎页集是一个**碎片化知识卡片站**：一条知识一张卡片，面向考点、金句、错题摘要和短笔记。它刻意不做复杂博客和知识库，打开就能写，写完就能抽一张复习。

线上地址：<https://qjr555.github.io/>

## 功能

- **一张卡只说一件事**：标题、正文、标签、类型、科目，内容保持短小。
- **标签与检索**：全文搜索标题、正文、标签、科目；按标签、科目、类型筛选。
- **随机翻卡**：每轮最多 12 张，先回想再翻面；记录「记住了 / 没记住」，统计复习足迹和连续天数。
- **公开分享**：把卡片压缩编码进链接，不需要登录、服务器或数据库。拿到链接的人可以直接打开、收进自己的卡片集。
- **分享卡片图片**：用 Canvas 生成 1080 × 1350 的竖版卡片 PNG。
- **Markdown 导入**：粘贴或拖入 `.md` / `.txt` / `.json`，自动拆分、预览、合并或替换。
- **数据属于你**：所有卡片保存在浏览器 `localStorage`，可导出 JSON / Markdown 备份。
- **本地优先 + PWA**：无外部字体、无追踪脚本；支持离线缓存和添加到主屏幕。
- **夜读模式**：日间纸感 / 夜间墨色两套主题。

## 快速开始

这是一个零构建的静态站点。直接打开 `index.html` 即可，或起一个本地服务器：

```bash
python -m http.server 8765
```

然后访问 <http://127.0.0.1:8765/>。

## Markdown 导入格式

每张卡片用 `---` 分隔，也可以用多个 `##` 标题分隔：

```md
## 复合函数的定义域
标签：数学、函数、易错
类型：笔记
科目：数学

求 `f(g(x))` 的定义域：先内后外，最后取交集。

---

## 楞次定律怎么快速判断？
标签：物理 电磁学
类型：概念
科目：物理

**增反减同，来拒去留。**
```

- `标签` 也可以用单独一行 `#数学 #函数`。
- `类型`、`科目`、`日期` 都可以省略。
- 没有标题时，第一行会作为标题。
- 也支持导入碎页集导出的 JSON 备份。

## 分享链接怎么工作

卡片内容会被压成紧凑的 JSON（优先使用浏览器原生 `CompressionStream`，不支持时回退到 Base64），放在 `?s=` 参数里：

```text
https://qjr555.github.io/?s=z...
```

没有任何内容上传到服务器。访问链接时由前端解码并渲染，因此链接可能很长，这是正常现象。

## 项目结构

```text
index.html                 # 应用外壳与对话框
404.html                   # GitHub Pages 404
assets/css/style.css       # 纸感视觉、响应式、暗色主题
assets/js/data.js          # 类型、科目、示例卡片
assets/js/markdown.js      # 安全的轻量 Markdown 渲染
assets/js/store.js         # localStorage 数据层
assets/js/importer.js      # Markdown / JSON 导入解析
assets/js/share.js         # 分享链接、压缩编码、Canvas 图片
assets/js/app.js           # 路由、视图与交互
manifest.webmanifest       # PWA 清单
sw.js                      # 离线缓存
```

## 部署

站点部署在 GitHub Pages 的 `master` 分支根目录。仓库推送后 GitHub Pages 会自动构建：

```bash
git add .
git commit -m "feat: 碎页集 知识卡片站"
git push origin master
```

## 说明

- 示例卡片是内容引子，可以在站内直接编辑、删除，或在「关于」里移除。
- 清除浏览器数据会清空本地卡片，建议定期在「关于」里导出 JSON 备份。
- 「公开分享」不做搜索收录或公开广场；它是**拿到链接即可查看**的单卡链接分享，避免把私人笔记意外发布出去。
